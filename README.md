## 📂 Project Structure

```text
📦 src
 ┣ 📂 api            # axios 인스턴스 설정
 ┣ 📂 assets         # 정적 리소스
 ┣ 📂 components     # 재사용 UI 컴포넌트
 ┣ 📂 constants      # 정적 데이터
 ┣ 📂 contexts       # 전역 상태 관리
 ┣ 📂 hooks          # 커스텀 훅 (로컬 스토리지)
 ┣ 📂 pages          # 라우팅되는 각 페이지 컴포넌트
 ┣ 📂 styles         # 공통 테마 설정
 ┗ 📜 App.js         # 최상위 라우팅 설정
```
